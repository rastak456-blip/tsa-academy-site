## 비교 방법

`main`은 그대로 두고 `feat/curriculum-feedback` 브랜치에서만 작업합니다. 원본과 수정본을 동시에 띄워서 비교합니다.

```bash
git worktree add "../TSA어학원 사이트-baseline" main
```

| 대상 | 주소 | 실행 |
| --- | --- | --- |
| 원본 (main) | http://localhost:4174 | `tsa-site-baseline` |
| 수정본 (feat/curriculum-feedback) | http://localhost:4173 | `tsa-site-preview` |

두 프리뷰 모두 `dist/`를 그대로 서빙하므로, 각 워크트리에서 `npm run build`를 먼저 실행해야 최신 상태가 반영됩니다.

코드 diff는 `git diff main...feat/curriculum-feedback` 또는 PR 화면에서 확인합니다.

## 7. 공통 디자인 원칙

위 항목에 반영되는 원칙입니다. 새로 만드는 화면에도 동일하게 적용합니다.

- 과정명과 페이지명이 설명형 문구보다 먼저 보이도록 정보 위계를 통일합니다.
- ESL과 IELTS는 강조색과 섹션 배경으로 구분하되, 전체 디자인 체계는 유지합니다.
- 같은 목적의 버튼은 모든 카드에서 같은 위치와 크기에 둡니다.
- 수업 유형별 색상 규칙을 과정 요약, 탭, 시간표에 일관되게 적용합니다.
- 반복되는 카드 구성은 비교표, 흐름도, 캘린더 등 정보 성격에 맞는 형태로 바꿉니다.
- 학생 이미지는 과정 대상과 수업 유형이 드러나는 장면을 우선 사용합니다.
