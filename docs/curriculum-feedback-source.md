# TSA 홈페이지 커리큘럼 콘텐츠 및 디자인 피드백

**검토 대상:**  **한국어 버전 전체 과정 안내 및 세부 교육과정 페이지**

전반적으로 제안한 교육과정 구조와 주요 콘텐츠가 전반적으로 잘 반영되어 있습니다. 이번 피드백은 과정명과 핵심 정보의 시각적 위계를 강화하고, 반복되는 카드 구성을 줄이며, ESL과 IELTS의 차이를 더 명확하게 보여주는 데 목적이 있습니다.

## 우선 수정 항목

| **우선순위** | **수정 항목** | **핵심 요청** |
| --- | --- | --- |
| **필수** | 과정 상담 버튼 | Partnership Inquiry가 아닌 학생 대상 과정 상담 또는 일반 문의 페이지로 연결 (추후 연결 필요) |
| **필수** | 과정 비교표 | ‘운영 과정’을 ‘일일 운영 구성’으로 변경 |
| **필수** | 현재 영어 수준과 가장 가까운 학습 목표를 선택해 보세요. | ‘현재 학습 목표에 가장 가까운 항목을 선택해 보세요.’로 수정 |
| **개선** | 정보 위계 | 설명 문구보다 ESL·IELTS 및 각 과정명을 더 크고 명확하게 표시 |
| **개선** | ESL·IELTS 구분 | 섹션 배경색과 강조색으로 두 과정군을 시각적으로 구분 |
| **개선** | 상세 페이지 시간표 | 수업 유형별 색상 체계를 모든 페이지에 동일하게 적용 |

## 1 전체 과정 안내 페이지

### 1.1 상단 영역

**히어로 영역 축소**

현재 히어로 영역이 커서 실제 과정 정보가 늦게 노출되고, 하단 소개 내용과 일부 반복되는 느낌이 있습니다.

**수정 요청 [개선]**  히어로 영역은 삭제하지 않고 높이와 여백을 줄여 간결하게 구성해 주세요. 제목, 소개 문구, [ESL 과정 보기], [IELTS 과정 보기] 버튼이 첫 화면 안에서 빠르게 인식되도록 조정해 주세요.

**대표 이미지 변경**

현재 이미지는 강사가 혼자 노트북을 보는 모습으로, 온라인 수업이나 강사 업무 장면처럼 보입니다.

**수정 요청 [개선]**  TSA의 대면 수업 특성이 드러나도록 성인 학생과 강사가 함께하는 1:1 수업 이미지로 변경해 주세요.

**상단 버튼 인터랙션**

두 버튼의 기본 상태와 마우스 오버 상태가 보다 명확하게 구분될 필요가 있습니다.

**수정 요청 [개선]**  [ESL 과정 보기], [IELTS 과정 보기] 버튼에 마우스를 올렸을 때 하늘색 강조 상태가 적용되도록 구성해 주세요.

### 1.2 전체 프로그램 한눈에 보기

**영역명 중복 조정**

작은 영역명 ‘전체 프로그램’과 큰 제목 ‘전체 프로그램 한눈에 보기’가 반복적으로 느껴집니다.

**수정 요청 [개선]**  작은 영역명을 ‘과정 안내’ 또는 ‘PROGRAM OVERVIEW’로 변경하거나 삭제해 주세요.

**과정군 제목 위계 강화**

현재 ‘ESL 과정’과 ‘IELTS 과정’은 작게 표시되고, 설명형 문장이 더 크게 보여 과정 구분이 약합니다.

**수정 요청 [개선]**  ‘ESL 과정’과 ‘IELTS 과정’을 각 영역의 대표 제목으로 크게 표시하고, 설명형 문장은 보조 문구로 한 단계 낮춰 주세요.

**과정 카드 정보 위계**

카드 안에서 Regular ESL, Regular+ ESL 등의 과정명보다 설명 문구가 더 크게 보입니다.

**수정 요청 [개선]**  각 카드에서는 과정명을 가장 크게 강조하고, 한 줄 과정 설명과 세부 설명을 그 아래에 배치해 주세요. IELTS 과정 카드에도 동일하게 적용해 주세요.

**버튼 위치 통일**

설명 길이에 따라 [과정 자세히 보기] 버튼의 세로 위치가 달라 보입니다.

**수정 요청 [개선]**  모든 과정 카드의 높이를 통일하고 [과정 자세히 보기] 버튼을 카드 하단 왼쪽에 고정해 주세요.

**ESL과 IELTS 시각적 구분**

ESL 카드와 IELTS 카드가 유사한 디자인으로 이어져 두 과정군의 차이가 충분히 드러나지 않습니다.

**수정 요청 [개선]**  ESL과 IELTS 영역에 서로 다른 강조색 또는 옅은 배경색을 적용하고, 두 영역 사이의 여백을 확대해 주세요. 전체 홈페이지 디자인 체계는 동일하게 유지합니다.

### 1.3 나에게 맞는 과정 찾기

**영역명 중복 조정**

작은 영역명과 큰 제목이 모두 ‘나에게 맞는 과정 찾기’로 동일합니다.

**수정 요청 [개선]**  작은 영역명은 ‘과정 추천’, 큰 제목은 ‘나에게 맞는 과정 찾기’로 구분해 주세요.

**안내 문구 수정**

현재 ‘현재 영어 수준과 가장 가까운 학습 목표를 선택해 보세요.’는 영어 수준과 학습 목표를 비교하는 의미로 읽힙니다.

**수정 요청 [필수]**  ‘현재 학습 목표에 가장 가까운 항목을 선택해 보세요.’로 수정해 주세요.

**카드 노출 방식 변경**

현재는 클릭하기 전부터 추천 과정이 보여 + 버튼을 눌러야 하는 이유가 약합니다.

**수정 요청 [개선]**  기본 상태에서는 학습 목표 질문만 노출하고, + 버튼을 클릭하면 추천 과정, 추천 이유, [과정 자세히 보기] 버튼이 펼쳐지도록 구성해 주세요. 추천 과정명은 굵게, 추천 이유는 일반 본문으로 표시하며 이탤릭은 사용하지 않습니다.

**마지막 카드 배치**

IELTS Guarantee 카드가 마지막 줄 왼쪽에 단독으로 남아 전체 균형이 약해 보입니다.

**수정 요청 [개선]**  마지막 카드를 중앙 정렬하거나 전체 너비로 배치해 주세요.

### 1.4 과정별 수업 구성 비교

**열 제목 수정**

‘운영 과정’ 열에는 8시간, 6시간, 필수 학습 세션 등 일일 운영 정보가 들어가 있습니다.

**수정 요청 [필수]**  ‘운영 과정’을 ‘일일 운영 구성’으로 변경해 주세요.

**ESL과 IELTS 구분**

하나의 표 안에서 두 과정군이 연속으로 배치되어 구분이 약합니다.

**수정 요청 [개선]**  표를 별도로 나누기보다 하나의 표 안에 ‘ESL PROGRAMS’, ‘IELTS PROGRAMS’ 구분 행을 추가하고 색상으로 구분해 주세요. 전체 과정 비교 기능은 유지합니다.

**내부 설명 문구 삭제**

‘이 영역에서는 과정 비교에 필요한 핵심 정보만 노출하며…’ 문구는 사용자 안내보다 내부 기획 설명에 가깝습니다.

**수정 요청 [개선]**  해당 문구는 홈페이지에서 삭제해 주세요.

### 1.5 수업 유형 안내

**카드 정렬**

현재 첫째 줄 3개, 둘째 줄 2개가 배치되어 있으나 둘째 줄이 왼쪽으로 치우쳐 보입니다.

**수정 요청 [개선]**  첫째 줄에는 1:1 Class, Small Group, Big Group을 배치하고, 둘째 줄에는 Elective와 Required Study Session을 중앙 정렬해 주세요.

**필수 과정 강조 방식**

Required Study Session 아래에 별도의 ‘선택이 아닌 필수 과정’ 영역이 추가되어 정보가 반복됩니다.

**수정 요청 [개선]**  하단 별도 안내 영역은 삭제하고, Required Study Session 카드 안에서 ‘선택 수업이 아닌 필수 과정’임을 강조해 주세요.

### 1.6 과정 상담

**상담 버튼 연결 수정**

현재 [과정 상담하기] 버튼이 에이전시 대상 Partnership Inquiry 페이지로 연결됩니다.

**수정 요청 [필수]**  학생 대상 과정 상담 또는 일반 문의 페이지로 연결해 주세요. 별도의 과정 상담 페이지가 없다면 연결할 페이지를 먼저 확정해 주세요.

## 2 ESL 과정 메인 페이지

**상단 제목 강화**

ESL 과정명이 설명형 제목보다 작게 보여 페이지의 정체성이 바로 드러나지 않습니다.

**수정 요청 [개선]**  ‘ESL 과정’을 상단 대표 제목으로 크게 표시하고, ‘실생활 영어 능력을 단계적으로 완성하는 과정’은 보조 문구로 배치해 주세요.

**과정 비교 방식 변경**

전체 과정 안내 페이지에서 이미 네 개 과정 카드를 보여주기 때문에 ESL 메인 페이지의 카드 반복은 불필요하게 느껴집니다.

**수정 요청 [개선]**  ‘과정 비교’를 ‘ESL 과정 비교’로 변경하고, 카드 4개 대신 과정명, 핵심 키워드, 주요 수업 구성을 한눈에 비교할 수 있는 표 또는 가로형 비교 구조로 구성해 주세요.

| **과정** | **핵심 키워드** | **주요 수업 구성** |
| --- | --- | --- |
| **Regular ESL** | 균형 | 1:1 + Small Group + Big Group |
| **Regular+ ESL** | 협업 | Small Group 확대 |
| **Intensive Speaking** | 1:1 집중 | 1:1 × 5 |
| **Power Speaking** | Speaking 극대화 | 정규수업 전부 1:1 |

**중급 이상 학습 확장 도식 변경**

현재 구성은 레벨 시스템 페이지의 단계형 그래픽과 유사하여, ESL 활동의 확장을 보여주는 목적이 약해집니다.

**수정 요청 [개선]**  레벨 단계가 아니라 학습 활동의 확장에 초점을 맞춰 ‘Basic Communication → Opinion Sharing → Discussion → Argumentation → Debate & Presentation’ 흐름의 원형 또는 가로형 도식으로 구성해 주세요.

## 3 ESL 과정별 상세 페이지

**과정명 강조**

Regular ESL, Regular+ ESL 등 과정명이 설명 문구보다 작아 과정 구분이 약합니다.

**수정 요청 [개선]**  각 상세 페이지에서 과정명을 가장 크게 표시하고, 과정의 한 줄 설명과 세부 설명을 아래에 배치해 주세요.

**8시간·6시간 탭**

두 과정 선택 버튼과 설명·시간표 사이의 간격이 좁고 선택 상태가 명확하지 않습니다.

**수정 요청 [개선]**  선택된 탭은 브랜드 컬러 배경과 흰색 글자, 선택되지 않은 탭은 흰색 배경과 컬러 테두리로 구분해 주세요. 두 버튼에 서로 다른 고정 색상을 사용하지 않고 활성·비활성 상태로 구분합니다. 버튼과 본문 사이에는 충분한 여백을 둡니다.

**추천 학습자 영역**

일반 글머리표만 사용되어 추천 대상이 눈에 잘 들어오지 않습니다.

**수정 요청 [개선]**  추천 학습자는 일관된 라인 아이콘과 체크 표시를 사용한 체크리스트 형태로 구성해 주세요. 이모지는 사용하지 않습니다.

**주요 학습 내용 가독성**

주요 학습 내용의 제목과 설명이 한 덩어리로 보여 핵심 영역이 빠르게 구분되지 않습니다.

**수정 요청 [개선]**  각 학습 영역을 아이콘, 영역명, 한 줄 설명으로 구성한 2열 또는 3열 카드 형태로 정리해 주세요.

**시간표 색상 규칙**

1:1, Small Group, Big Group, Elective, Required Study Session의 구분이 표 안에서 충분히 드러나지 않습니다.

**수정 요청 [개선]**  수업 유형별 색상과 라벨을 정하고 모든 ESL·IELTS 상세 페이지의 수업 구성 요약과 시간표에 동일하게 적용해 주세요.

### 3.1 과정별 추가 요청

- Regular ESL: 상단 이미지는 성인 학습자와 강사가 함께하는 1:1 수업 이미지로 구성
- Regular+ ESL: 일일 수업 구성에서 Small Group × 4가 명확하게 강조되도록 표시
- Regular+ ESL: 공식 수업명 Group Communication은 시간표에서 영문으로 유지
- Intensive Speaking: 일일 수업 구성에서 1:1 × 5가 핵심으로 보이도록 강조
- Power Speaking: Level 1–4의 Presentation Skills & Practice가 Level 5+의 Debate Skills & Practice로 확장되는 흐름을 도식으로 제시

## 4 IELTS 과정 메인 및 상세 페이지

**ESL 과정과 시각적 구분**

현재 IELTS 페이지가 ESL 페이지와 유사한 레이아웃과 색상으로 구성되어 시험 대비 과정의 차별성이 약합니다.

**수정 요청 [개선]**  IELTS 페이지에는 네이비 또는 보라 계열의 강조색을 적용하고, Mock Test와 목표 Band 관리가 핵심으로 보이도록 구성해 주세요. 기본 레이아웃 체계는 ESL 페이지와 일관되게 유지합니다.

**과정 카드 버튼 위치**

과정 설명 길이에 따라 [과정 자세히 보기] 버튼 위치가 달라질 수 있습니다.

**수정 요청 [개선]**  Pre-IELTS, Regular IELTS, IELTS Guarantee 카드의 높이를 통일하고 버튼을 카드 하단 왼쪽에 고정해 주세요.

**Mock Test & Review 시각화**

텍스트만으로 운영 주기를 설명하면 Pre-IELTS, Regular IELTS, IELTS Guarantee의 차이를 빠르게 비교하기 어렵습니다.

**수정 요청 [개선]**  과정별 Mock Test 주기를 캘린더 형태로 보여주고, ‘Mock Test → Review / Error Analysis → Clinic → 보완 학습’ 흐름을 함께 시각화해 주세요.

## 5 레벨 시스템 페이지

**페이지 구성 차별화**

레벨 시스템 페이지가 ESL·IELTS 과정 설명 페이지와 유사한 카드와 텍스트 구조로 보일 수 있습니다.

**수정 요청 [개선]**  과정 소개 페이지와 달리 진단과 성장 경로가 중심이 되도록 인포그래픽형 페이지로 구성해 주세요. ‘Level Assessment → Level Placement → Level-Matched Learning → Progress Review’ 흐름과 Level 1–10 학습 경로가 핵심으로 보이도록 합니다.

## 7 공통 디자인 원칙

- 과정명과 페이지명이 설명형 문구보다 먼저 눈에 들어오도록 정보 위계를 통일합니다.
- ESL과 IELTS는 강조색과 섹션 배경으로 구분하되, 전체 홈페이지의 디자인 체계는 동일하게 유지합니다.
- 같은 목적의 버튼은 모든 카드에서 동일한 위치와 크기로 배치합니다.
- 수업 유형별 색상 규칙을 정하고 과정 요약, 탭, 시간표에 일관되게 적용합니다.
- 반복되는 카드 구성은 비교표, 흐름도, 캘린더 등 정보 성격에 맞는 시각화로 변경합니다.
- 학생 이미지는 과정 대상과 수업 유형이 드러나도록 성인 학습자와 강사가 함께하는 장면을 우선 사용합니다.
